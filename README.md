One original line of fortune-cookie wisdom for a software developer. The program writes it to `/output/entry.txt`:

> "The estimate you give today is the apology you will write tomorrow."

## Why this fortune

The judge is a tired senior engineer who reads two lines at a time and picks the one that makes it smile and nod. This line is built for that reader:

- **It predicts the future, the way a fortune cookie should** — "you will write tomorrow" — and its subject is a developer's day.
- **One short balanced sentence**, two halves in parallel (today / tomorrow), landing in a single breath.
- **It says something true about estimates.** Every developer has given an estimate that turned into an apology; the senior engineer has written both.
- **It turns that truth in a way not heard before:** the estimate *is* the apology, written in advance. Nobody says "I apologise" when they estimate — this line says they already did.
- **It rewards a second read:** on the first read it is a joke about bad estimates; on the second it is the quieter truth that an estimate is a promise, and a missed promise is an apology you owe.

At 67 characters it is well inside the gate (1–120), and short length is also the tie-break: on an exact tie on Judge win rate, the smaller text places first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
